# StarMap

Статическая карта и трекер исследования Honkai: Star Rail.

## GitHub Pages

1. Добавь файлы проекта в репозиторий, сохранив папку `docs`.
2. В **Settings → Pages → Build and deployment** выбери **Deploy from a branch**.
3. Укажи свою ветку (например, `main`), папку **/docs** и сохрани настройки.

Стартовая страница находится в `docs/index.html`. Все пути к ресурсам относительные. Для локальной проверки открой этот файл или запусти `python -m http.server 8000 --directory docs`.

## Данные

Снимок HoYoLAB от 13 ноября 2026 года содержит 9 групп миров и режимов, 98 локаций, 657 планов и 5 453 опубликованные метки. Связанные комнаты и платформеры входят в каталог основной локации. Все планы лежат в `docs/maps`, кроме исходного плана Морского в `docs/seafeld-city.png`.

- `docs/world-data.js` содержит снимок карты. `docs/catalog.js` добавляет вручную проверенные гайды и ссылки для сверки.
- Переключатель этажей меняет план, а поиск по всем этажам показывает вложенные сундуки в том же списке, что и остальные находки. Выбор такой находки переключает план.
- У награды один ID в локации. Поле `parent` указывает на вход с `container: true`. Сундук сохраняет категорию `treasure` и учитывается самостоятельно. Справочные карточки Game8 для сундуков парка не прибавляются к уже импортированным наградам.
- `jade: null` означает неизвестную сумму. Итог аккаунта охватывает известные награды из каталога и зависит от ручных отметок. Прогресс хранится в браузере для текущего сайта.
- Снимок AppSample от 12 ноября 2026 года выявил восемь этажей с более высоким числом меток хотя бы одного сравнимого типа. Сайт отмечает их для сверки.
- Покрытие карт соответствует снимку HoYoLAB. Пропущенные официальной картой находки, пошаговые решения и суммы наград требуют отдельной сверки с AppSample, Game8 и игрой.
